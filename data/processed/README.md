# Processed Dataset

## Dataset

This folder contains the cleaned and processed epidemiological data prepared from the original Ebola outbreak dataset for the:
**AI-Driven Multisource Ebola Outbreak Prediction Model**

## Processing

The original dataset was cleaned and prepared for machine learning through steps such as:
- Data cleaning
- Date processing
- Country filtering
- Handling missing values
- Data transformation
- Preparation for feature engineering and model development

## Countries Used

For the current prototype, the processed dataset contains data from:
- **Guinea**
- **Sierra Leone**
Liberia was not included in the current processed dataset.
This country selection applies specifically to the current prototype and may be expanded in future iterations.
