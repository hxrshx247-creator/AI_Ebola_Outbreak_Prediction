# Raw Dataset

## Dataset

This folder contains the original Ebola outbreak dataset used as the primary epidemiological data source for the project:
**AI-Driven Multisource Ebola Outbreak Prediction Model**
The dataset contains Ebola outbreak information from the 2014–2016 West Africa Ebola epidemic, including country- and date-based case and death information.

## Source

The dataset was obtained from **Kaggle** and is based on publicly available Ebola outbreak data.

## Usage in This Project

The raw dataset is preserved in its original form and is not modified. It serves as the source dataset for data cleaning, preprocessing, feature engineering, and subsequent machine learning experiments.
